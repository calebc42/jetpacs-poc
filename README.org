* Jetpacs — An Android Implementation of EBP

This branch is the spec-driven evolution of the Jetpacs platform. It exists to prove the EBP foundation and to be copied from — not to be the one true mobile Emacs.

Code from any earlier Jetpacs POC or branch, including `poc/v1`, `poc/v2`, and `slop-fork/main`, may be reused, copied, merged, ported, or adapted. Lineage does not determine correctness: reused code must be built and verified against the current normative =../ebp/SPEC.md=. If required behavior is not defined there, expand the normative specification and align its contract projection, goldens, and affected conformance tests before treating the behavior as compliant.

The original LLM-generated proof of concept on `slop-fork/main` is reusable implementation evidence and design input, not protocol authority.

Further development of Jetpacs is pending Emacs Bridge Protocol development.
